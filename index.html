Featured Project

DHL Shipping Automation

Built in-house at YesAgain to remove manual shipping data entry and book DHL labels for orders worldwide.

✓ Live in Production at YesAgain

From 2 hours of manual work
to 2 minutes — automated

Every day, our team was manually copying order details from Airtable into the DHL portal one by one — entering names, addresses, weights, dimensions for every single shipment. One typo meant a failed delivery. I built a system that handles all of it automatically, from data pull to label download, with a live dashboard showing real-time progress.

⚙️ Automation Flow
1
n8n triggers the workflow automatically when new orders arrive
2
Python pulls all orders from Airtable directly via API
3
Data validated & transformed, with the correct importer of record and VAT details applied for each destination country
4
Bulk submitted to DHL API — all shipments created in one call
5
All labels downloaded as ZIP — print-ready in seconds
6
Live Flask dashboard streams real-time logs as the process runs
